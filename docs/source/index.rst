What is Raven?
--------------

Raven is an open-source reference implementation and testing platform for the Medicolegal Death Investigation (MDI) FHIR Implementation Guide (IG). It provides a tool for testing conformance to the MDI FHIR IG, demonstrating major MDI data exchange workflows, and managing partner testing for events such as HL7 Connectathons. 

Raven also serves as an educational tool, providing examples in FHIR data formats (JSON and XML) while browsing records. This allows user to review how information is mapped between major MDI data fields and the underlying FHIR resources.

1. **Testing Features:**: FHIR validation, record comparison, and testing event management.
2. **Reference and Educational Features:** FHIR exploration, workflow simulation.

Raven is intended to aid developers in implementing the MDI FHIR record format by validating the data against MDI IG guidelines and FHIR-based extended API operations. For more information on each Raven tool components, Raven’s MDI CSV schema, or MDI FHIR standard please see the corresponding sections in this document, accessible through the table of contents below or the sidebar navigation menu.
